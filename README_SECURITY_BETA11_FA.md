# اصلاحات فنی و امنیتی beta.11

- مسیرهای قدیمی /spy، /whisper، /barge، /hangup، /remove_from_queue، /queues و /queue/* در HTTP با 410 مسدود شده‌اند. تنها API جدید با احراز هویت، CSRF، نقش، محدوده صف و گیت زمانی معتبر است.
- خروجی عمومی داده زنده از سرور ماسک می‌شود؛ دسترسی viewer به شناسه کانال نیز مسدود است.
- Parser AMI برای ServiceLevelPerf و MemberName استاندارد Asterisk 20 اصلاح و با ورودی استاندارد تست شده است.
- کش درون‌فرایندی ۲ ثانیه‌ای درخواست‌های هم‌زمان پنل را تجمیع می‌کند؛ هنگام قطع ارتباط داده قدیمی به‌عنوان تازه ارائه نمی‌شود. این **جایگزین** Collector دائمی Event-driven/WebSocket نیست.
- پاسخ HTTP موفق فرمان به معنی موفقیت نهایی تلفنی نیست. نتیجه AMI با state=ami_accepted_unverified مشخص می‌شود.
- ظاهر و package metadata فقط نام SaneQueue دارند. کد داخلی و قراردادهای import هنوز در qpanel/ هستند؛ حذف واقعی این وابستگی نیازمند مهاجرت و اجرای کامل suite است. مجوز MIT و اعلان حقوقی در LICENSE و NOTICE محفوظ‌اند.
- این نسخه هنوز برای Production مناسب نیست. استفاده فقط روی سرور تست و تماس آزمایشی با اجازه اشخاص.
- پسوردهای AMI منتشرشده قبلی باید عوض شوند. از write=all، write=command یا permit باز استفاده نکنید.

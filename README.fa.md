# صانع · SaneQueue

مانیتورینگ زندهٔ صف برای مراکز تماس مبتنی بر Asterisk، با مجوز MIT.

**نسخهٔ 2.1.0-beta.21 · [English](README.md)**

حالت اختیاری Collector پایدار اکنون داشبورد را به Redis و WebSocket احراز هویت‌شده متصل می‌کند. خواندن عادی وب اتصال AMI جدید ایجاد نمی‌کند. [راه‌اندازی فارسی](docs/REALTIME_DEPLOYMENT.fa.md)، [معماری](docs/REALTIME_ARCHITECTURE.fa.md)، [ممیزی جدید و امتیاز سخت‌گیرانه](docs/AUDIT_BETA21.md)، [ورود مدیر و بازیابی رمز](docs/ADMIN_ACCESS.fa.md). گزارش‌گیری فاز بعد است.

![داشبورد فارسی با داده ساختگی](docs/images/dashboard-fa.png)

امکانات این نسخه شامل نمایش زنده صف‌ها، تماس‌های منتظر، وضعیت کارشناسان، سطح خدمت، فیلتر و جست‌وجو، پوسته روشن و تیره، نمای دیواری، نمودار زنده، کاربران و مجوزهای صف، حداقل آمادگی، دلایل توقف، ثبت عملیات، برنامه شیفت و دفترچه تلفن است.

توقف و ادامه، وزن کارشناس، عضویت پویا، اولویت و قطع تماس آزمایشی روی Asterisk 20.12 تأیید شده‌اند. شنود، نجوا و ورود به مکالمه از مسیر ChanSpy انجام می‌شوند؛ پذیرش فرمان AMI معادل تأیید صدا نیست و آزمون شنیداری در هر نصب لازم است. انتقال مستقیم و با مشورت، پارک/بازیابی و Pickup اکنون روی PBX آزمایشی و با تأیید کاربر آزموده شدند؛ این کنترل‌ها همچنان بتا و وابسته به نصب هستند. CRM، WebRTC، هوش مصنوعی و گزارش‌های تاریخی در این نسخه تحویل نشده‌اند. گزارش‌گیری فاز بعدی پروژه است.

[راه‌اندازی حالت پایدار](docs/REALTIME_DEPLOYMENT.fa.md) · [نصب پایه](docs/INSTALL.fa.md) · [راهنمای کاربری](docs/USER_GUIDE.fa.md) · [جدول امکانات](docs/FEATURES.md) · [سازگاری و بار سرور](docs/COMPATIBILITY.md) · [نتیجه آزمون‌ها](docs/VALIDATION.md)

```bash
git clone https://github.com/SaneHajiha/sanequeue.git
cd sanequeue
sudo env PYTHON=python3.11 bash scripts/install.sh
```

Python جداگانهٔ ۳٫۱۰ تا ۳٫۱۲ لازم است. Python سیستم ایزابل را جایگزین نکنید. نصب‌کننده کاربر مستقل و رمز هش‌شده ایجاد می‌کند و سرویس را روی localhost می‌آورد. تنظیمات تولیدشدهٔ ایزابل و مسیر تماس‌ها را تغییر نمی‌دهد.

نسخهٔ پایهٔ beta.19 دارای ۲۲۴ آزمون موفق بود؛ نتایج هستهٔ جدید در گزارش ممیزی جاری ثبت شده‌اند. تست واقعی روی Rocky 8.10 و Asterisk 20.12 انجام شده است؛ نسخه‌های ۱۶ و ۱۸ با نمونه رویداد آزمایش شده‌اند. سازگاری عملی همه نسخه‌های ایزابل و همه پروژه‌ها هنوز تأیید نشده و نسخه بتا است. تصاویر راهنما داده ساختگی دارند.

اعلان حقوقی کدهای اقتباس‌شده و کتابخانه‌های همراه در LICENSE و NOTICE محفوظ است. این پروژه مستقل از Issabel، Asterisk، FOP2 و ویپینگ است.

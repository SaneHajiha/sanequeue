# صانع · SaneQueue

مانیتورینگ زندهٔ صف برای مراکز تماس مبتنی بر Asterisk، با مجوز MIT.

**نسخهٔ 2.1.0-beta.20 · [English](README.md)**

این نسخه Collector مستقل و اختیاری با اتصال پایدار AMI و Redis اضافه می‌کند؛ رابط فعلی هنوز به آن مهاجرت نکرده است. [معماری](docs/REALTIME_ARCHITECTURE.fa.md)، [ممیزی سخت‌گیرانه و امتیاز](docs/AUDIT_20261024.fa.md)، [ورود مدیر و بازیابی رمز](docs/ADMIN_ACCESS.fa.md). WebSocket و گزارش‌گیری کامل هنوز تحویل نشده‌اند.

![داشبورد فارسی با داده ساختگی](docs/images/dashboard-fa.png)

امکانات این نسخه شامل نمایش زنده صف‌ها، تماس‌های منتظر، وضعیت کارشناسان، سطح خدمت، فیلتر و جست‌وجو، پوسته روشن و تیره، نمای دیواری، نمودار زنده، کاربران و مجوزهای صف، حداقل آمادگی، دلایل توقف، ثبت عملیات، برنامه شیفت و دفترچه تلفن است.

توقف و ادامه، وزن کارشناس، عضویت پویا، اولویت و قطع تماس آزمایشی روی Asterisk 20.12 تأیید شده‌اند. شنود، نجوا و ورود به مکالمه از مسیر ChanSpy انجام می‌شوند؛ پذیرش فرمان AMI معادل تأیید صدا نیست و آزمون شنیداری در هر نصب لازم است. انتقال، Pickup، کنترل پارک، CRM، WebRTC، هوش مصنوعی و گزارش‌های تاریخی هنوز قابلیت تحویل‌شده نیستند. گزارش‌گیری فاز بعدی پروژه است.

[نصب فارسی](docs/INSTALL.fa.md) · [راهنمای کاربری](docs/USER_GUIDE.fa.md) · [جدول امکانات](docs/FEATURES.md) · [سازگاری و بار سرور](docs/COMPATIBILITY.md) · [نتیجه آزمون‌ها](docs/VALIDATION.md)

```bash
git clone https://github.com/SaneHajiha/sanequeue.git
cd sanequeue
sudo env PYTHON=python3.11 bash scripts/install.sh
```

Python جداگانهٔ ۳٫۱۰ تا ۳٫۱۲ لازم است. Python سیستم ایزابل را جایگزین نکنید. نصب‌کننده کاربر مستقل و رمز هش‌شده ایجاد می‌کند و سرویس را روی localhost می‌آورد. تنظیمات تولیدشدهٔ ایزابل و مسیر تماس‌ها را تغییر نمی‌دهد.

نسخهٔ پایهٔ beta.19 دارای ۲۲۴ آزمون موفق بود؛ نتایج هستهٔ جدید در گزارش ممیزی جاری ثبت شده‌اند. تست واقعی روی Rocky 8.10 و Asterisk 20.12 انجام شده است؛ نسخه‌های ۱۶ و ۱۸ با نمونه رویداد آزمایش شده‌اند. سازگاری عملی همه نسخه‌های ایزابل و همه پروژه‌ها هنوز تأیید نشده و نسخه بتا است. تصاویر راهنما داده ساختگی دارند.

اعلان حقوقی کدهای اقتباس‌شده و کتابخانه‌های همراه در LICENSE و NOTICE محفوظ است. این پروژه مستقل از Issabel، Asterisk، FOP2 و ویپینگ است.

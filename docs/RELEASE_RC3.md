# SaneQueue 2.1.0-rc.3

RC3 retains the RC2 screen and report search, direct links and responsive navigation. It groups the dashboard controls by metric source and queue alert settings and improves contrast on the queue policy form.

The live waiting trend spaces samples by elapsed time and labels them in Tehran time. The latest twelve observed samples are available as a keyboard-accessible table. Changing the selected queues or source retains the existing sample boundary.

For rollout and recovery, use the [Persian operating guide](INSTALL_RC1.fa.md) with the RC3 archive and checksum. Live-telephony acceptance remains distinct from the application rollout.

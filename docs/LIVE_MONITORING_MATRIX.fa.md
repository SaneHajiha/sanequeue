# نقشه جامع امکانات مانیتورینگ زنده

مقایسه با [ماژول ویپینگ](https://voiping.ir/product/ماژول-گزارشات-و-مانیتورینگ-آنلاین-صف/) و [FOP2](https://www.fop2.com/)؛ هیچ کد اختصاصی از این محصولات استفاده نشده است. **گزارش تاریخی، Excel و نمودار دوره‌ای فعلاً خارج از محدوده است**.

| امکان | وضعیت SaneQueue beta | نکتهٔ تست |
|---|---|---|
| صف‌ها، تعداد منتظر، زمان انتظار، تماس و جایگاه | پیاده‌سازی اولیه | AMI زنده تست نشده |
| وضعیت اپراتور آماده، مشغول، Pause و نامعتبر | اولیه | تطابق StateInterface بررسی شود |
| فیلتر صف/کارشناس، جست‌وجو، هشدار و Wallboard | اولیه | تست کارایی و RTL |
| نقش‌ها، محدودیت صف، حداقل نیروی آماده | اولیه | تست هم‌زمانی و RBAC |
| تغییر اولویت و ابتدای صف، قطع تماس | اولیه | فقط تماس آزمایشی |
| Pause/Resume، عضویت پویا، penalty | اولیه | فقط صف آزمایشی |

## اصول کیفیت

- نمایش واضح تفاوت «متصل»، «داده ساختگی»، «داده کهنه» و «قطع ارتباط».
- تمام عملیات خطرناک server-side مجوز، هویت و audit داشته باشند.
- UI حرفه‌ای فارسی RTL و انگلیسی، رنگ معنادار، دسترس‌پذیری، کارت‌های خوانا و واکنش‌گرایی موبایل.
- عدم وابستگی به داده واقعی در پیش‌نمایش لوکال.

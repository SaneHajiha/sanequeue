# SaneQueue 2.1.0-rc.2

The RC2 interface adds keyboard-accessible screen and report search over the permitted navigation entries. Screen and report links can be reopened directly. Back and Forward restore the selection, and a request for an unavailable destination resolves to the nearest permitted view.

Live queue and member search accepts Persian and Arabic forms of letters and digits. The monitoring filters can be cleared in one step. The visible release marker follows the installed version in both writing directions.

The installation and rollback process is the same as in the [RC1 Persian guide](INSTALL_RC1.fa.md), with the RC2 archive, directory and checksum file. Site acceptance and deployment evidence are tracked separately from browser fixtures and software tests.

# گزارش‌ساز مراجعهٔ صف

گزارش‌ساز زیر بخش گزارش‌ها قرار دارد. دادهٔ این نسخه فقط «مراجعه به صف» است؛ یک مکالمه که چند صف را طی می‌کند می‌تواند چند مراجعه داشته باشد. این ابزار SQL آزاد، گزارش عمومی همهٔ CDRها یا خروجی فایل با چیدمان سفارشی نیست.

۱. بازهٔ تاریخ بالای گزارش‌ها را حداکثر ۳۱ روز انتخاب کنید. تاریخ‌های جدول با منطقهٔ زمانی تهران و تقویم زبان پنل نمایش داده می‌شوند.
۲. در فرم گزارش‌ساز، صف‌ها و ستون‌ها را انتخاب کنید. صف‌های این فرم مستقل از فیلتر صف عمومی صفحه هستند؛ فقط صف‌های مجاز خودتان قابل استفاده‌اند.
۳. برای جدول جزئیات، گروه‌بندی را خالی بگذارید. برای خلاصه، حداکثر دو گروه از صف، کارشناس و نتیجه انتخاب کنید.
۴. نتیجه و حداقل/حداکثر انتظار یا مکالمهٔ صف برحسب ثانیه اختیاری‌اند. خالی یعنی بدون شرط؛ صفر یک شرط عددی واقعی است. مقدار نامعلوم با شرط عددی مطابقت ندارد.
۵. «پیش‌نمایش» را بزنید. جدول حداکثر ۵۰ ردیف در هر صفحه نشان می‌دهد؛ «صفحه بعد» ادامه را می‌آورد. خلاصه تا ۵۰۰ گروه است؛ بیشتر از سقف خطا می‌دهد و بریده نمی‌شود.
۶. نام وارد و «ذخیره» را بزنید. قالب فقط برای حساب شماست. انتخاب همان قالب و ذخیرهٔ مجدد نسخهٔ تازه می‌سازد؛ نسخهٔ قبلی تغییر نمی‌کند. «جدید» یک قالب مستقل می‌سازد. حداکثر ۱۰۰ قالب برای هر حساب و ۵۰ نسخه برای هر قالب نگهداری می‌شود؛ حذف خودکار داده یا فایل صوتی وجود ندارد.

## معنی شاخص‌ها

| شاخص | تعریف و مخرج |
|---|---|
| تعداد مراجعه | تعداد ردیف‌های مراجعهٔ صف مطابق فیلتر؛ نه مکالمهٔ یکتا |
| پاسخ دارای زمان معتبر | تعداد مراجعه‌هایی که زمان پاسخ معلوم دارند |
| رهاشده | تعداد مراجعه با نتیجهٔ ثبت‌شدهٔ رهاشدن |
| میانگین انتظار معلوم | مجموع انتظار معلوم / `wait_known` |
| میانگین مکالمهٔ صف معلوم | مجموع مکالمهٔ معلوم / `talk_known` |
| مجموع مکالمهٔ صف | مجموع قطعه‌های معلوم صف؛ نه الزاماً کل مکالمه پس از انتقال |

نامعلوم صفر نیست. نبود ردیف به معنی اثبات صفر تماس واقعی یا کامل‌بودن همهٔ منابع نیست. برای مجموع گروه‌ها، هر مراجعه فقط در گروه خودش قرار می‌گیرد؛ مجموع زمان کارشناسان چندصفی در این ابزار شاخص حضور یا occupancy نیست. ردیف‌ها بر اساس زمان ورود در `[شروع، پایان)` و برای کارشناس با رعایت زمان شروع انتساب حساب محدود می‌شوند.

پیش‌نمایش هر درخواست، وضعیت فعلی آرشیو را می‌خواند؛ بین صفحه‌ها ممکن است دادهٔ دیررس وارد شود. نسخهٔ قالب ثابت است، نه snapshot دادهٔ پیش‌نمایش. برای فایل با snapshot ثابت از مرکز خروجی رسمی استفاده کنید.

شماره‌ها در backend بر اساس مجوز فعلی پوشانده می‌شوند. کارشناس فقط مراجعه‌های مرتبط با هویت داخلی مجاز خودش را می‌بیند. اگر دسترسی یکی از صف‌های قالب پس گرفته شود، پیش‌نمایش آن قالب بسته می‌شود؛ صف حذف‌شده پنهانی از محاسبه کنار نمی‌رود. قالب حساب دیگر با شناسه نیز قابل دریافت نیست.

## محدودیت و عیب‌یابی

- قالب خروجی سفارشی هنوز به CSV/XLSX/PDF وصل نیست. برای فایل، از مرکز خروجی رسمی استفاده کنید؛ ترتیب ستون‌ها و گروه‌بندی گزارش‌ساز به آن مرکز منتقل نمی‌شود.
- حداکثر درخواست ۱۶ KiB، مهلت خواندن آرشیو ۲ ثانیه، صفحهٔ backend حداکثر ۱۰۰ ردیف و خلاصه حداکثر ۵۰۰ گروه است. عبور از سقف یا مهلت خطا می‌دهد.
- اگر نسخهٔ قالب هم‌زمان عوض شد، دوباره بارگذاری و ویرایش کنید. خطای مجوز با دادن مجوز حدسی یا نمایش اطلاعات صف دیگر دور زده نمی‌شود.
- منبع فقط آرشیو محلی گزارش‌هاست؛ این ماژول هیچ فرمان AMI، عملیات تماس یا خواندن مستقیم SQL از مرکز تلفن اجرا نمی‌کند.

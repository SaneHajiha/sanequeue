# راه امن تست SaneQueue با Asterisk / Issabel

**هیچ رمز، توکن، فایل `manager.conf` واقعی یا کلید SSH را در چت یا GitHub عمومی قرار ندهید.** از راه‌های زیر مرحله‌ای جلو بروید.

## فاز صفر: اطلاعات بدون رمز
روی سرور ایزابل به‌صورت محلی خروجی دستورهای صرفاً خواندنی زیر را تهیه کنید (شماره‌ها و شناسه‌های خصوصی را پوشش دهید):

```bash
asterisk -rx 'core show version'
asterisk -rx 'module show like app_queue'
asterisk -rx 'queue show'
asterisk -rx 'manager show settings'
asterisk -rx 'core show channels count'
```

خروجی `manager show settings` ممکن است IPهای شبکه و اطلاعات حساس داشته باشد؛ قبل از ارسال حذف شوند. هیچ دستور DialPlan یا Reload برای این مرحله لازم نیست.

## فاز یک: اتصال **فقط خواندنی** در شبکهٔ خصوصی

- حساب AMI جدا و موقتی، از طریق GUI رسمی Issabel/FreePBX در صورت پشتیبانی یا مدیریت امن `manager_custom.conf` تعریف شود.
- فقط از IP ثابت ماشین آزمایش یا یک SSH tunnel با bind روی `127.0.0.1` قابل دسترسی باشد؛ AMI/5038 را روی اینترنت باز نکنید.
- برای فاز خواندن، در صورت سازگاری نسخه فقط دسترسی مناسب مشاهدهٔ queue و call events اختصاص داده شود؛ `write=none`، بدون Originate/Hangup/QueuePause.
- رمز را خارج از Git و خارج از متن گفتگو با روش امن محلی وارد کنید.
- تست فقط QueueStatus، CoreShowChannels و event streaming است؛ اگر لازم شد `manager show commands` را با دقت بررسی کنید.

## فاز دو: کنترل‌ها فقط روی PBX آزمایشی

- یک صف آزمایشی، کارشناس آزمایشی و تماس تست ایجاد شود؛ مسیر تماس مشتری واقعی نباشد.
- مجوزهای AMI به ازای عمل (QueuePause, QueueAdd, QueueRemove, QueueChangePriorityCaller, Originate / ChanSpy) مرحله‌به‌مرحله و موقت اضافه شوند؛ صدای تماس فقط با سیاست سازمانی و رضایت/اطلاع‌رسانی لازم شنود شود.
- اول نقش، صف مجاز، CSRF، مقصد شنود، و حداقل آماده‌بودن نیرو بررسی شود.
- همهٔ نتایج و مجوزها بعد از تست بازبینی و دسترسی موقت جمع شود.

## دسترسی ChatGPT

چت عادی به‌صورت پیش‌فرض دسترسی ترمینال به LAN یا سرور شما ندارد. اگر در Work/Computer Use اتصال مجاز دارید، می‌توان صفحه/مرورگر را با مجوز شما بررسی کرد، ولی این جایگزین دسترسی شبکهٔ امن و کنترل‌شدهٔ SSH/AMI نیست. راه جایگزین: اسکریپت تشخیص **خواندنی** را در شبکهٔ خود اجرا و خروجی پاک‌سازی‌شده را بارگذاری کنید. اتصال مستقیم عمومی SSH/AMI برای ربات پیشنهاد نمی‌شود.

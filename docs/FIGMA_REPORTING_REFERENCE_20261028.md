# Reporting and Persian calendar: provisional Figma reference

Created 2026-10-28 in the existing SaneQueue design file. This is an additive,
editable reference, not a certified pixel match or the live reporting application.

- [Dedicated page](https://www.figma.com/design/eKxCAaXf89ch2xu2KppEM5?node-id=10-2): `10:2`
- [Reporting desktop frame](https://www.figma.com/design/eKxCAaXf89ch2xu2KppEM5?node-id=10-3): `10:3`, 1440 × 1185
- [Persian calendar frame](https://www.figma.com/design/eKxCAaXf89ch2xu2KppEM5?node-id=10-65): `10:65`, 480 × 418

Only synthetic values are included. No PBX screenshot, phone records, audio,
credentials or other private content were uploaded. No existing design node was
modified or removed. Existing dark Button and KPI components were instantiated;
existing local dark-color and geometry variables were reused. Font discovery
confirmed Vazirmatn is available, and all 82 rendered text nodes explicitly use it.

Structural read-back from the composition reported 21 frames, 82 text nodes,
46 component instances and 7 editable vectors. No image-filled nodes exist.
The chart is a bounded illustrative editable vector, not the complete runtime
30-day chart. Date controls are a visual reference, not an interactive prototype.
This reference omits the full lower chart grid, responsive states and all table rows.

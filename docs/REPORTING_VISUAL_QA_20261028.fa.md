# اصلاح نمودار و تقویم گزارش‌ها — ۲۰۲۶/۱۰/۲۸

این مرحله اصلاح محلی سورس و آزمون مرورگر است؛ روی پورت ۵۰۰۰ یا ۱۸۸۹۷ نصب نشده و به GitHub ارسال نشده است.

## تغییرات قابل بررسی

- نمودار خطی برای روند زمانی، با فاصلهٔ زمانی واقعی و گسست در نبود داده؛ نمودار میله‌ای برای مقایسه و بازهٔ تک‌نقطه‌ای.
- عنوان و راهنمای یک‌بار نمایش‌داده‌شده، اعداد خوانا، رنگ متناسب با تم، جدول معادل و راهنمای مقدار با صفحه‌کلید.
- اندازه‌گذاری مجدد هنگام تغییر عرض؛ صفحه‌بندی ۱۲ دستهٔ میله‌ای یا ۶۰ نقطهٔ خطی. سقف ورودی ۱۰۰۰ دسته و چهار سری با اعلام محدودیت؛ این سقف جای خروجی کامل گزارش را نمی‌گیرد.
- خروجی PNG/SVG از همان صفحه و تم، با دوره و عنوان؛ تغییر فیلتر، تم یا صفحه، خروجی در انتظارِ قدیمی را بی‌اعتبار می‌کند.
- تقویم شمسی فارسی و میلادی انگلیسی با انتخاب مستقیم ماه/سال، صفحه‌کلید، امروز، انتخاب بازهٔ سریع و بازگشت فوکوس.
- مقدار ارسالی همچنان ISO میلادی است. بازه‌ها روز مدنی تهران‌اند؛ تاریخ پایان شامل همان روز است. انتخاب بازه به‌تنهایی درخواست گزارش نمی‌فرستد.
- انتخاب ماه شمسی با گروه‌بندی ماهانه فرق دارد: گروه‌بندی موجود backend میلادی است و اکنون صریحاً همین برچسب را دارد؛ روزهای واقعی و ماه جزئی روی نمودار مشخص‌اند. گروه‌بندی واقعی ماه شمسی در این مرحله ساخته نشده است.

## روش بررسی

تصاویر تازهٔ پنل زنده پیش از اصلاح بررسی شدند. ترکیب موقت مؤلفه‌های جدید با دادهٔ همان صفحه نیز فقط داخل مرورگر انجام شد؛ این روش معادل نصب و پذیرش runtime جدید نیست. تصاویر واقعی و نشست خصوصی خارج از مخزن نگهداری می‌شوند.

کارگاه مستقل از همان فایل‌های JavaScript/CSS محصول استفاده می‌کند، با دادهٔ ساختگی و درخواست‌های غیرمحلی مسدودشده. ماتریس فارسی/انگلیسی، روشن/تیره، ۳۹۰/۱۴۴۰ پیکسل، تصاویر صفحه و تقویم، axe، فوکوس، صفحه‌کلید، تغییر عرض بدون reload، صفر/نامعلوم/خطا و دانلود واقعی PNG/SVG آزمایش می‌شوند. تصاویر مرجع ابتدا بازبینی شدند؛ سپس مقایسه بدون به‌روزرسانی مرجع اجرا می‌شود. نتیجهٔ دقیق فرمان‌ها در `docs/ai-workflow/TEST_RESULTS.md` است.

پیش‌نمایش محلی:

`http://127.0.0.1:18910/?view=report-design&locale=fa&theme=dark`

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH='C:/path/to/playwright-browsers'
npm run build --prefix tools/ui-workbench
npm run build-storybook --prefix tools/ui-workbench
npm test --prefix tools/ui-workbench
```

اگر Vite از قبل اجراست، از داخل پوشهٔ کارگاه با `UI_EXTERNAL_SERVER=1` مستقیماً Playwright CLI را اجرا کنید؛ دو سرور روی یک پورت اجرا نکنید. نخستین اجرای clean clone نیازمند نصب وابستگی‌های توسعه و Chromium است.

## محدودیت‌های تأیید

اتصال CUA به مرورگر شخصی هنوز خطای راه‌اندازی دارد؛ رفع آن ادعا نمی‌شود. تست Chromium مستقل پروژه اجرا شده است. درخواست نمایش پیش‌نمایش در Codex با وضعیت queued برگشت؛ دیده‌شدن آن توسط کاربر تأیید نشده است.

مرجع افزودهٔ Figma به‌دلیل سقف ابزار تصویر نهایی قابل بررسی نداد و هنوز پیش‌نویس است؛ مرجع تأیید این مرحله، مرورگر و سورس است. ساخت Storybook موفق است، با هشدار اختیاری مجوز تنظیمات global و اندازهٔ bundle مدیر؛ Storybook روی سرور تماس نصب نمی‌شود.

این آزمون‌ها جای بررسی نصب تازهٔ Flask/Jinja، همهٔ صفحات دارای نمودار، مرورگرهای دیگر، صفحه‌خوان و سناریوهای تماس/مجوز/بار را نمی‌گیرند. توسعه‌های باز، به‌ویژه تجمیع ماهانهٔ بزرگ حضور و رتبه‌بندی، در `REPORTING_COMPLETION_CHECKLIST.fa.md` باقی‌اند.

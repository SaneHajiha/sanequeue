# SaneQueue 2.1.0-rc.5

RC5 retains the [report and recording-scope changes in RC4](RELEASE_RC4.md). It reduces vertical space in the access editor by aligning checkboxes beside their labels and giving menu groups the full form width.

Elapsed durations use the same hours, minutes and seconds format in the shift tables, unanswered offers, queue outcome aggregates, and organizational queue reports. Counts, percentages, timestamps and chart axis units retain their meaning.

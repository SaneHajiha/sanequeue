# نصب و نگهداری · beta.18

Python جداگانهٔ ۳٫۱۰ تا ۳٫۱۲، Git و systemd لازم است. روی Rocky 8 از Python 3.11 موازی استفاده کنید؛ Python و بسته‌های اصلی ایزابل را تغییر ندهید. برای ایزابل ۴ قدیمی، نصب روی سرور لینوکسی جدا با دسترسی محدود AMI مناسب‌تر است.

```bash
git clone https://github.com/SaneHajiha/sanequeue.git
cd sanequeue
sudo env PYTHON=python3.11 bash scripts/install.sh
sudo systemctl enable --now sanequeue
```

نصب‌کننده مشخصات AMI و رمز جدید پنل را تعاملی می‌پرسد. مسیر برنامه `/opt/sanequeue`، تنظیمات `/etc/sanequeue/config.ini` و داده خصوصی `/var/lib/sanequeue` است. نصب موجود را بازنویسی نمی‌کند. سرور بدون حساب اولیه اجرا نمی‌شود. یک worker و چهار thread وب لازم است؛ تعداد worker را افزایش ندهید.

سرویس پیش‌فرض روی `127.0.0.1:5000` است. برای دسترسی کاربران، پراکسی HTTPS با گواهی سازمان تنظیم کنید. فقط هنگامی که برنامه پشت پراکسی مورد اعتماد و روی loopback است، `SANEQUEUE_TRUST_PROXY=1` و `SANEQUEUE_HTTPS=1` را در سرویس قرار دهید. نمونه در `deploy/nginx.conf.example` است.

حساب AMI اختصاصی و محدود به IP پنل بسازید. مجوز هر Action را با `manager show command` بررسی کنید؛ برای حل خطای ناشناخته، دسترسی گسترده ندهید. پورت ۵۰۳۸ را اینترنتی نکنید. SIP و PJSIP جدا تشخیص داده می‌شوند؛ کانال مبهم رد می‌شود. در نصب‌های خاص از بخش `device_channels` استفاده کنید.

حساب‌ها، داخلی اختصاصی سرپرست و دسترسی صف‌ها را در «کاربران و دسترسی‌ها» تعریف کنید. فرمان‌های کنترلی به فعال‌سازی گیت همان صف و نشست نیاز دارند. وضعیت «پذیرفته‌شده» تأیید مستقل اجرای فرمان یا کیفیت صدا نیست. برنامه شیفت به‌صورت خودکار وضعیت PBX را تغییر نمی‌دهد.

پیش از ارتقا، از تنظیمات و تمام پوشه داده خصوصی نسخه پشتیبان بگیرید. فقط سرویس پنل را متوقف و مسیر نسخه جدید را جایگزین کنید؛ نیازی به ری‌استارت Asterisk نیست. برای بازگشت، مسیر سرویس و پشتیبان قبلی را برگردانید. رمزها، فایل نشست، داده تماس و پایگاه داده را عمومی نکنید.

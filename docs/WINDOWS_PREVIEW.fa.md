# اجرای امن پیش‌نمایش SaneQueue در ویندوز

این پیش‌نمایش **فقط با داده‌های ساختگی** اجرا می‌شود؛ به سرور ایزابل وصل نمی‌شود و نباید به‌عنوان تست واقعی AMI یا نسخه آماده نصب تلقی شود.

1. آرشیو `SaneQueue_windows_demo_2026-10-22.zip` را در یک پوشه جدید استخراج کنید؛ محتویاتش را روی نسخه فعال QPanel کپی نکنید.
2. **Python 3.11** و دسترسی اینترنت برای نصب کتابخانه‌های `pip` لازم است. اگر Python 3.11 نصب نیست، آن را از منبع رسمی نصب کنید.
3. روی `RUN_DEMO_WINDOWS.bat` دوبار کلیک کنید؛ یا در PowerShell از همان پوشه اجرا کنید: `./RUN_DEMO_WINDOWS.bat`.
4. آدرس `http://127.0.0.1:8765/` را در مرورگر خود باز کنید. صفحه‌های «مرکز عملیات تماس» و صف‌ها را بررسی کنید.
5. برای بستن سرور تست، در پنجره ترمینال `Ctrl+C` بزنید.

در صورت مشکل، خروجی پنجره را همراه با نسخه Python ارسال کنید. نصب کتابخانه‌ها ممکن است به‌خاطر محدودیت اینترنت، پراکسی یا نسخه Python ناموفق باشد. سرویس روی `127.0.0.1` اجرا می‌شود؛ نباید به IP عمومی Bind شود.

## مسیر جداگانه تست کد

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_sanequeue -v
```

**هشدار:** صفحه نمایش آزمایشی ممکن است دکمه‌های کنترل تماس را نشان دهد، ولی عملیات واقعی روی تلفن مشتری اجرا نمی‌شود. ادعای موفق بودن تمام امکانات روی PBX تنها پس از تست ایزوله درست است.

## نسخه beta.2
برای دیدن نمای صف‌ها، تماس‌های زنده و کارشناسان، در منوی کناری به‌ترتیب گزینه‌های «صف‌ها»، «تماس‌های زنده» و «کارشناسان» را انتخاب کنید. داده‌ها کاملاً آزمایشی هستند و هیچ فرمانی به PBX ارسال نمی‌شود.

بهتر است در پیش‌نمایش از Python 3.11 استفاده شود. اسکریپت `RUN_DEMO_WINDOWS.bat` فقط روی `127.0.0.1:8765` گوش می‌دهد و نباید به اینترنت منتشر شود.

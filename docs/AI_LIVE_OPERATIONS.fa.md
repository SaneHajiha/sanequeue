# هوش مصنوعی در مانیتورینگ زندهٔ SaneQueue — طرح پیشنهادی

**فاز فعلی:** AI در نسخهٔ beta.3 عملیاتی نشده است؛ همهٔ تحلیل‌های فعلی بر اساس قواعد روشن هستند. **گزارش‌گیری تاریخی خارج از محدودهٔ این فاز است.**

## فرصت‌های کاربردی

1. **Live Supervisor Copilot:** هر ۱۰–۱۵ ثانیه یک خلاصهٔ قابل‌ردیابی از ازدحام، صف بدون نیروی آماده، انتظار طولانی، خرابی Trunk، و توصیهٔ عملی (صرفاً پیشنهاد، بدون اجرای خودکار) بدهد.
2. **Anomaly detection:** در پنجرهٔ لغزان ۵–۱۵ دقیقه‌ای الگوهای غیرعادی نرخ ورود تماس، زمان انتظار، و تغییر وضعیت آماده/استراحت را شناسایی کند؛ نیازی به گزارش دوره‌ای ندارد، ولی حافظهٔ کوتاه‌مدت لازم است.
3. **Staffing suggestions:** هشدار بدهد «صف ۸۰۰۱ سه تماس منتظر و فقط یک نیروی آماده دارد» و پیشنهاد جابه‌جایی عضو یا بررسی شیفت را با ذکر دلیل و دادهٔ لحظه‌ای ارائه دهد. تصمیم نهایی با سرپرست است.
4. **Conversation assistance (opt-in):** تشخیص گفتار فارسی، متن زنده، خلاصهٔ مکالمه، کلیدواژه‌ها و پیشنهادی برای پاسخ اپراتور. به API ضبط/مدیا، منابع پردازشی و رضایت و کنترل دسترسی نیاز دارد. به‌طور پیش‌فرض خاموش.
5. **Quality-of-service assistant:** MOS/jitter/packet loss فقط در صورت دسترسی به معیارهای RTP/RTCP/SIP و با بیان سطح اطمینان. صرف اتصال AMI چنین داده‌هایی را تضمین نمی‌کند.
6. **PBX health diagnosis:** تشخیص قطعی AMI، افزایش صف انتظار، unreachable شدن داخلی، خطاهای ترانک و کندی event delivery با توضیح قابل‌درک.

## معماری امن و کم‌هزینه

`Asterisk/Issabel -> AMI (read-only) -> Event aggregator -> Live state / ring buffer -> Rules + optional local LLM -> Supervisor UI`

- موتور تصمیم‌گیری عملیاتی ابتدا rule-based باشد، قابل بازپخش و قابل تست؛ LLM فقط توضیح و اولویت‌بندی را انجام دهد.
- مدل محلی مثل Ollama در سرور جداگانه و با دادهٔ حداقلی، اتصال بیرونی اختیاری و پیش‌فرض غیرفعال.
- دادهٔ شماره تلفن و نام مشتری پیش از مدل ماسک شود؛ تماس‌ها و متن مکالمه فقط با رضایت/سیاست سازمانی قابل پردازش‌اند.
- استنتاج LLM باید محدود، sandboxed و **بدون مجوز اجرای AMI** باشد؛ تصمیم حساس مثل قطع تماس، شنود، انتقال یا Pause هرگز خودکار نشود.
- در پنل تفاوت «هشدار قطعی» و «پیشنهاد مدل» آشکار باشد، منبع و زمان داده نشان داده شود و نتایج نامطمئن قابل تشخیص باشند.

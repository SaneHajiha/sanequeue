# SaneQueue 2.1.0-rc.4

Historical reports share an elapsed duration display such as `2:45:32`. Report tables align headings and values in both writing directions, the call-details close button remains visible during scrolling, and advanced CDR filters start collapsed. Queue overview includes a comparison chart, and opening the CDR report loads its trend and extension charts for the selected dates.

The access editor separates panel sections, queue controls, recording actions, and organizational grants. A supervisor can have visibility of a queue without access to its audio. The existing organizational assignment and authorization rules scope direct-call playback by extension. Playback and download retain independent actions, and the queue recording scope constrains both.

The [Persian operating guide](INSTALL_RC1.fa.md) applies with the RC4 archive and checksum. Installation on the lab host should preserve current accounts, SQL settings and the PBX idle gate.

# SaneQueue 2.1.0-rc.6

Extension performance displays compact outcome bars and whole-number axes for counts. Report extension filters accept bare digits, including Persian and Arabic digits, and match exact observed SIP and PJSIP endpoints. The scrollable picker allows selecting the exact technology where both are observed.

The access panel provides one form to select an account and an existing unit or create a unit, optionally assign an extension or queue, set membership dates and select report permissions. The server checks the existing management permission and CSRF and commits the organizational changes in one transaction. Existing account and queue policy operations, individual revocation and assignment history are available separately.

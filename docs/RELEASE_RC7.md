# SaneQueue 2.1.0-rc.7

The access center starts with a searchable user directory and role filter. A three-step account editor brings identity, queue and recording grants, panel sections, and final review into a keyboard-accessible dialog. It uses the existing account and queue-policy save, and distinguishes creation from editing to protect existing accounts. The optional organization workflow opens with the selected account and keeps membership and organization grants separately reviewable.

The layout follows the staged add-user workflow in [Microsoft 365](https://learn.microsoft.com/en-us/microsoft-365/admin/add-users/add-users?view=o365-worldwide) and the separation of role and scoped permissions in [Atlassian Administration](https://support.atlassian.com/user-management/docs/how-does-product-access-work/).

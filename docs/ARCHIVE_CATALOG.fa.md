# کاتالوگ اپراتوری نسخه‌های آرشیو

این ابزار **نسخهٔ کامل دیتابیس گزارش‌گیری را با برچسب ماه** نگهداری می‌کند.
برچسب `2026-10` به معنی فیلتر رویدادهای اکتبر نیست؛ رویدادهای همهٔ ماه‌ها،
checkpointها و projectionهای موجود در همان snapshot باقی می‌مانند. این ابزار
شاردینگ رویدادها، پارتیشن دیتابیس، مسیریابی خودکار گزارش بین ماه‌ها، کوچک‌سازی
دیتابیس یا بازیابی کامل نصب نیست. صوت تماس، حساب‌ها، تنظیمات و دیتابیس سایر
ماژول‌ها در این bundle قرار نمی‌گیرند و برنامهٔ پشتیبان جدا لازم دارند.

منبع حذف، جابه‌جا، checkpoint یا جایگزین نمی‌شود. تعویض دیتابیس زنده، اتصال PBX،
زمان‌بندی یا endpoint وب برای مسیر فایل نصب نمی‌شود. اپراتور دستور را روی مسیر
محلی مورد اعتماد اجرا می‌کند. ساخت، راستی‌آزمایی و بازیابی از پیاده‌سازی موجود
`sanequeue.reporting.backup` استفاده می‌کند و دادهٔ commit‌شده در WAL را حفظ می‌کند.

## استفاده

پوشهٔ والد کاتالوگ باید موجود باشد. مسیر را خارج از پوشهٔ عمومی وب و روی دیسک
خصوصی محلی نگه دارید. همهٔ دستورات را با یک کاربر سیستم‌عامل مجاز اجرا کنید.
در یونیکس ریشه و پوشهٔ bundles باید متعلق به همان کاربر با مجوز ۰۷۰۰ و دیتابیس
با مجوز ۰۶۰۰ باشند. symlink و مجوز عمومی رد می‌شوند و خودکار اصلاح نمی‌شوند.

```sh
python -m sanequeue.reporting.archive_catalog --root /private/sanequeue-catalog create /var/lib/sanequeue/reporting.sqlite3 --month 2026-10 --key monthly-2026-10-01
python -m sanequeue.reporting.archive_catalog --root /private/sanequeue-catalog list --limit 50
python -m sanequeue.reporting.archive_catalog --root /private/sanequeue-catalog status
python -m sanequeue.reporting.archive_catalog --root /private/sanequeue-catalog verify ENTRY_UUID
python -m sanequeue.reporting.archive_catalog --root /private/sanequeue-catalog restore ENTRY_UUID /private/restore-new-directory
```

فهرست فقط فرادادهٔ ثابت و cursor صفحهٔ بعد (`--before`) را می‌دهد. وضعیت حداکثر
۱۰۰ درخواست ثبت‌نشده را نشان می‌دهد. هیچ‌کدام فایل‌ها را دوباره hash نمی‌کنند و
`verified_now=false` است. برای صحت فعلی checksum، ساختار و مرز رویداد، `verify`
را اجرا کنید. مسیر منبع و کلید درخواست در خروجی عمومی نیست. SHA-256 خرابی نسبت
به کاتالوگ را تشخیص می‌دهد؛ در برابر مالک مخربی که کل ذخیره‌سازی را تغییر دهد،
امضای احراز اصالت محسوب نمی‌شود.

بازیابی فقط در **پوشهٔ جدید** مجاز است و مقصد موجود رد می‌شود. هیچ دیتابیس
درحال‌کار انتخاب یا جایگزین نمی‌شود. نسخهٔ بازیابی‌شده را جدا بررسی کنید و تصمیم
مهاجرت زنده را مستقل بگیرید.

اگر اپراتور یک bundle کامل معتبر را از قبل در `ROOT/bundles/UUID` کپی کرده است:

```sh
python -m sanequeue.reporting.archive_catalog --root /private/sanequeue-catalog register ENTRY_UUID --month 2026-09 --key imported-2026-09
```

شناسه دقیقاً ۳۲ کاراکتر hexadecimal کوچک است؛ مسیر دلخواه به register، verify یا
restore داده نمی‌شود. bundle ثبت‌شده را ویرایش نکنید؛ تغییر فایل یا manifest با
مدخل ثابت کاتالوگ ناسازگار است و راستی‌آزمایی رد می‌شود.

## قطع فرایند و نگهداری

قبل از شروع، درخواست پایدار با UUID رزرو می‌شود. ثبت نهایی فقط بعد از manifest
تکمیل و بررسی موفق bundle است. اگر فرایند بعد از تکمیل و قبل از ثبت کاتالوگ قطع
شد، همان create را با منبع، ماه و کلید قبلی تکرار کنید؛ همان UUID بررسی و ثبت
می‌شود. استفاده از کلید قبلی برای منبع یا ماه دیگر خطاست. رشد دیتابیس منبع باعث
تغییر snapshot قبلی نمی‌شود؛ برای snapshot تازه کلید تازه بدهید.

bundle ناقص بدون نشانگر معتبر، incomplete می‌ماند؛ نه پذیرفته و نه بازنویسی
می‌شود. شواهد را برای بررسی حفظ و برای تلاش تازه کلید دیگری انتخاب کنید. نسخهٔ
ثبت‌شدهٔ مفقود یا تغییرکرده خودکار از نو ساخته نمی‌شود. مدخل‌ها و درخواست‌ها با
trigger تغییرناپذیرند. حذف خودکار snapshot، درخواست یا شواهد ناقص وجود ندارد.

سقف‌ها: ۱۰۰۰ درخواست در کل با احتساب تلاش ناقص؛ ۱۰۰ مدخل در صفحه؛ ۱۰۰ درخواست
ثبت‌نشده در status؛ زمان پیش‌فرض ۶۰ ثانیه و سقف ۳۰۰ ثانیه برای عملیات؛ اندازهٔ
پیش‌فرض یک گیگابایت و سقف هشت گیگابایت برای هر snapshot. گزینه‌های کلی
`--seconds`، `--max-mib` و `--reserve-mib` قبل از نام دستور می‌آیند. ذخیرهٔ آزاد
پیش‌فرض ۶۴ مگابایت، علاوه بر فضای کار نسخه‌برداری است. بودجهٔ مشترک زمان به‌صورت
مشارکتی بررسی می‌شود؛ syscall دیسک تضمین زمان واقعی سخت ندارد. رسیدن به سقف، کار
تازه را رد می‌کند و اطلاعات نگهداری‌شده حذف نمی‌شود.

از دیتابیس کاتالوگ و تمام bundles به شکل سازگار پشتیبان بگیرید؛ فرادادهٔ تنها
یا کپی نیمه‌تمام پوشه، پشتیبان کامل آرشیو نیست. تست‌ها محلی و مصنوعی‌اند و شامل
قطع واقعی فرایند پیش از ثبت کاتالوگ، تکرار درخواست، bundle ناقص، صحت و بازیابی
در مقصد تازه می‌شوند؛ تأیید بازیابی عملیاتی روی سرورهای متفاوت نیستند.

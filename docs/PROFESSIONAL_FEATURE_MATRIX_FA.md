# ماتریس امکانات حرفه‌ای SaneQueue — نسخه 2.1.0-beta.2

مبنای مقایسه: مستندات رسمی **FOP2** (`https://www.fop2.com/`)، ماژول ویپینگ (صفحه محصولی که کاربر معرفی کرده)، **QueueMetrics** (`https://www.queuemetrics.com/`)، پروژه متن‌باز **OpDesk** (`https://github.com/Ibrahimgamal99/OpDesk`) و VICIdial (`https://www.vicidial.com/features/`). این فهرست «شبیه‌سازی» امکانات دیگران نیست و کد یا گرافیک اختصاصی آن‌ها کپی نشده است.

وضعیت‌ها: **اولیه** = رابط و مسیر کد وجود دارد، تست کامل با ایزابل نشده؛ **آزمایشی** = مسیر کنترل وجود دارد و به مجوز/تماس آزمایشی وابسته است؛ **برنامه توسعه** = هنوز اجرا نمی‌شود؛ **خارج محدوده** = فعلاً درخواست نشده.

## مانیتورینگ صف و مرکز تماس

| قابلیت | وضعیت فعلی | نکته |
|---|---|---|
| صف، تعداد منتظر، جایگاه تماس و زمان انتظار | اولیه | برای صف 8001 با QueueStatus آزمایش می‌شود؛ اتصال زنده هنوز تأیید کاربر را می‌خواهد |
| نام/شماره تماس‌گیرنده | اولیه | شماره‌ها در UI ماسک می‌شوند؛ API محلی هنوز نیازمند احراز هویت واقعی در نسخه production است |
| کارشناسان آماده، مشغول، Pause، Unavailable | اولیه | از QueueMember؛ وضعیت مبتنی بر Device State است |
| تماس‌های جاری، میزان اشغال کارشناسان | اولیه | داده لحظه‌ای محدود؛ جزئیات channel با CoreShowChannels فعلاً غیرفعال |
| SLA/Service Level و شمارنده‌های Completed/Abandoned | اولیه | مقادیر جمع‌شونده از آخرین بازنشانی صف هستند، نه گزارش تاریخی |
| میانگین انتظار از آمار صف | اولیه | آماری، نه میانگین محاسبه‌شده روی تمام تماس‌های فعلی |
| فیلتر صف/کارشناس و جست‌وجو | اولیه | قابلیت UI موجود؛ در تست فقط صف 8001 مجاز است |
| نمایش RTL فارسی/EN، پوسته تیره/روشن، موبایل | اولیه | پیش‌نمایش تست شده؛ ارزیابی UX محصولی ادامه دارد |
| Wallboard و هشدار مدت انتظار/ازدحام/Pause | اولیه | قواعد محلی و هشدار صوتی پایه؛ سیستم اعلان سازمانی کامل نیست |
| نمایش وضعیت اتصال، خطا و قدیمی‌شدن داده | اولیه | تشخیص Live/Demo و stale، نیازمند تست قطع تونل واقعی |
| مدیریت حداقل تعداد کارشناس آماده | اولیه | کد محدودکننده وجود دارد؛ در صف تک‌عضوی آزمایشی حداقل عمداً صفر است |

## کنترل و سرپرستی

| قابلیت | وضعیت فعلی | نکته |
|---|---|---|
| Pause/Resume با علت | آزمایشی | AMI QueuePause؛ فقط صف/عضو تست |
| افزودن/حذف عضو پویا | آزمایشی | QueueAdd/QueueRemove؛ اعضای ثابت از Issabel |
| Penalty | آزمایشی | QueuePenalty |
| تغییر اولویت/انتقال به ابتدای صف | آزمایشی | QueueChangePriorityCaller، نیاز به تماس منتظر واقعی |
| قطع تماس منتظر | آزمایشی | Hangup فقط روی کانالی که اکنون در QueueEntry است |
| Listen/Whisper/Barge | آزمایشی | Originate/ChanSpy؛ تست با رضایت و داخلی supervisor |
| نقش‌های Admin/Supervisor/Agent/Viewer | اولیه | کد نقش‌ها هست؛ اجراکننده محلی هنوز خودکار Admin است، نه محصول امن چندکاربره |
| Audit عملیات | اولیه | لاگ API؛ نیاز به مدیریت نگهداشت و هویت واقعی دارد |
| انتقال Blind/Attended | برنامه توسعه | نیاز به کانال دقیق و کنترل انتقال |
| Pickup و Park/Parked calls | برنامه توسعه | نیاز به AMI Actions و نمایش Park slot |
| Conference controls | برنامه توسعه | نیاز به کنفرانس و API اختصاصی |
| شروع/توقف Recording، پخش Voice Mail | برنامه توسعه | رضایت/مجوز و تنظیمات ذخیره‌سازی لازم است |

## اکوسیستم و قابلیت‌های پیشرفته

| قابلیت | وضعیت فعلی | نکته |
|---|---|---|
| Presence همه داخلی‌ها، DND، Ringing و SIP Registration | برنامه توسعه | فعلاً فقط QueueMember دیده می‌شود |
| Trunk Status، تماس ورودی/خروجی و ظرفیت خطوط | برنامه توسعه | نه از QueueStatus به تنهایی |
| دفترچه تلفن، Caller ID normalization و CRM pop-up | برنامه توسعه | API مستقل لازم است |
| WebRTC Softphone و Click-to-dial | برنامه توسعه | نیاز به WebRTC/PJSIP و احراز هویت مستقل |
| دکمه اعلان Browser Push / اعلان صوتی پیشرفته | برنامه توسعه | هشدار صوتی پایه موجود است |
| AI Copilot (توضیح ازدحام، پیشنهاد ظرفیت، STT) | برنامه توسعه | فقط طرح؛ هیچ تصمیم تغییردهنده تماس به AI سپرده نمی‌شود |
| Multi-PBX / Multi-tenant / RBAC تولیدی | برنامه توسعه | جداسازی مستحکم نیاز است |
| Load testing، امنیت Production و نصب استاندارد Linux | برنامه توسعه | هنوز قابل استقرار تجاری نیست |
| گزارش‌گیری تاریخی، Excel، KPI دوره‌ای | خارج محدوده فعلی | به درخواست کاربر به فاز بعد موکول شده است |

## معیار گذار به نسخه پایدار

- اتصال تأییدشده Asterisk 20.12.0 با QueueStatus/AMI واقعی؛ تست خطای تونل و Login
- تست تمام کنترل‌های سرپرست روی تماس/صف آزمایشی با ثبت Audit
- احراز هویت واقعی کاربران، RBAC چندنقشی، TLS/reverse proxy و محرمانگی تماس‌گیرنده
- تست حداقل 30 تماس هم‌زمان، کارایی، چند صف و قابلیت بازگشت نسخه
- مستندات فارسی/انگلیسی، CI، منبع کامل GitHub، Release و Changelog درست

**این نسخه یک نمونه آزمایشی برای بررسی عملی است؛ ادعای برابری امکانات با FOP2/OpDesk/ویپینگ ندارد.**

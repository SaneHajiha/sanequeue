# ورود و بازیابی مدیر

رمز پیش‌فرض عمومی مانند admin/admin وجود ندارد. نصب‌کنندهٔ جدید باید رمز مدیر را از خود مدیر بگیرد و فقط هش آن را در `local_accounts.json` نگه دارد. حساب بدون registry معتبر نباید ورود ناشناس باز کند.

در سرور آزمایشی این پروژه نام کاربری `admin` است. رمز تصادفی اولیه در فایل خصوصی تحویل دسترسی روی رایانهٔ مالک و نسخهٔ خصوصی `/root/sanequeue-beta18-access.json` سرور نگه داشته شده است. این فایل‌ها در مخزن یا بستهٔ عمومی قرار نمی‌گیرند. رمز در رابط عمومی یا API نمایش داده نمی‌شود.

اگر رمز در دسترس نیست، از ترمینال امن سرور و مسیر state واقعی همان نصب استفاده کنید:

```bash
cd /opt/sanequeue
sudo -u sanequeue .venv/bin/python scripts/reset_password.py \
  --state /var/lib/sanequeue --username admin
sudo systemctl restart sanequeue
```

این دستور مربوط به نسخه‌ای است که `scripts/reset_password.py` را دارد. دو بار رمز ۱۲ تا ۲۰۰ نویسه‌ای را به‌صورت مخفی می‌پرسد؛ رمز را در argument، history یا log ننویسید. فقط حساب موجود را به‌روزرسانی می‌کند؛ نقش و داخلی را عوض نمی‌کند و با نام کاربری اشتباه حساب تازه نمی‌سازد. در بازهٔ بازیابی، ویرایش کاربران از وب را متوقف نگه دارید. restart سرویس وب برای خواندن registry تازه و بی‌اعتبار شدن sessionهای قدیمی است؛ Asterisk را restart نکنید.

اگر نصب در مسیر دیگری است، مسیرها را مطابق همان نصب عوض کنید. برای مشاهدهٔ داخلی مدیر از صفحهٔ مدیریت کاربران استفاده کنید؛ رمز حساب از هش قابل بازیابی نیست.

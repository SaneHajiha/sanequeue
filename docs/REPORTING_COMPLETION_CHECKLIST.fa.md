# معیار تکمیل گزارش‌گیری SaneQueue

به‌روز: ۲۰۲۶/۱۰/۲۸. این سند وضعیت جاری را از یادداشت‌های تاریخی فازها جدا می‌کند. «کد موجود» به معنی تأیید همهٔ مسیرهای تلفنی، نسخه‌های مرکز تلفن یا بار واقعی نیست. master شامل تمام توسعه نیست؛ شاخه feature/reporting-phase2 مبنای کار است.

| حوزه | وضعیت کد و محدوده | پذیرش باقی‌مانده |
|---|---|---|
| صف و شاخص‌ها | مراجعه/پاسخ/رهاشدن، SLA با مخرج، ASA و صدک، مقایسه و نقشه ساعات | تطبیق سناریوهای تلفنی جدید و نسخه‌های مختلف |
| کارشناس چندصفی | عملکرد، اجتماع زمان حضور، علت توقف، ACW/AHT/اشغال فقط با شواهد | ابزار ثبت ACW برای منابع فاقد وضعیت صریح |
| زنگ بدون پاسخ | گزارش مستقل RINGNOANSWER، گروه/ریز/نمودار و سقف منابع | نصب نسخهٔ جدید و آزمون واقعی عدم پاسخ؛ مقیاس بالا نیازمند projection اختصاصی |
| تماس و صوت | جزئیات، مسیر مبتنی بر شواهد، پخش/دانلود و audit مستقل | مسیرهای پیچیدهٔ انتقال/کنفرانس و مالکیت چندمرحله‌ای |
| CDR و خطوط | مبدأ واقعی/CID/DID/ترانک، جستجوی دوطرفه، ساعت/روز/طول شماره | ترانک خارجی و دادهٔ واقعی تاریخ‌دار |
| هپی‌کال کارشناس | دورهٔ صریح، ریز تماس/صوت و توقف‌ها؛ داخلی و خارجی جدا | ترانک خارجی؛ دورهٔ اعلام‌شده اثبات حضور نیست |
| کیفیت انسانی | فرم نسخه‌دار، امتیاز وزنی و یادداشت زمان‌دار | خوانایی کامل و سناریوهای مجوز روی سرور |
| نظرسنجی مشتری | فرم/پاسخ/CSAT؛ adapter اختیاری فقط مسیر اثبات‌شده | فعال‌سازی و آزمون تلفنی hook؛ ضبط آزاد خودکار هنوز کامل نیست |
| VIP و مسدودی | برچسب زمانی/SLA و ورود مشاهدات منبع | جمع‌آوری خودکار منبع مسدودی، نه فقط import |
| نمودارها | روند، صف، کارشناس، ترانک، شیفت، توقف، VIP؛ SVG/PNG محلی | بررسی کامل روشن/تیره/موبایل و PNG مرورگر |
| خروجی استاندارد | CSV/XLSX/PDF خصوصی و ثابت با مجوز جاری؛ برنامهٔ دوره‌ای | آزمون نصب/بازیابی و سقف منابع روی سامانه‌های دیگر |
| گزارش‌ساز | ستون/فیلتر/گروه و قالب خصوصی؛ dataset مراجعهٔ صف | خروجی و برنامهٔ دوره‌ای دقیقاً مطابق تعریف سفارشی؛ dataset مستقل CDR |
| متن و AI | ASR خصوصی، جستجوی متن، تحلیل مولد اختیاری loopback | دقت واقعی فارسی و بار سرویس مدل؛ فعال‌سازی خودکار ندارد |
| نگهداری | بدون حذف خودکار؛ پشتیبان آرشیو، کاتالوگ و restore بدون بازنویسی | تقسیم داده‌های آرشیو و بازیابی کامل نصب/رسانه/حساب‌ها |

## پنج شکاف توسعه‌ای مشخص

۱. خروجی و زمان‌بندی منطبق با تعریف سفارشی گزارش‌ساز، روی snapshot ثابت و با مجوز دوباره‌بررسی‌شده.
۲. بازه‌های Ring Group/Follow-Me پیش از صف و انتظار آن‌ها، مستقل از انتظار صف و بدون دوباره‌شماری legها.
۳. workflow پیگیری تماس رهاشده با شناسهٔ اقدام و اثبات نتیجهٔ تماس برگشتی؛ برابری شماره به‌تنهایی کافی نیست.
۴. دریافت تلفنی خودکار نظرسنجی/پیام صوتی با رضایت و session معتبر؛ upload دستی و hook اختیاری را کامل تلقی نکنید.
۵. منبع‌های خودکار تاریخیِ وضعیت/مسدودی و آرشیوهای دوره‌ای/بازیابی کامل؛ دادهٔ ثبت‌نشده را نمی‌توان از روی حدس بازسازی کرد.

پیش از بستن توسعه، برای هر قابلیت باید مسیر پنل، مجوز، منبع داده، واحد و مخرج، رفتار نبود داده، خروجی و آزمون مشخص باشد. «همهٔ محصولات قابلیت کمتری دارند» معیار قابل اثبات این پروژه نیست. آخرین نتیجهٔ CI در PR همان commit ثبت می‌شود. هیچ رمز، فایل صوتی خصوصی یا دیتابیس زنده در مخزن منتشر نمی‌شود.

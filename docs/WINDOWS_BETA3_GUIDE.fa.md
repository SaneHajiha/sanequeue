# رفع نمایش نسخه قدیمی در ویندوز

در عکس ارسالی، صفحهٔ `127.0.0.1:8765` نسخهٔ 2.0 قدیمی است. فایل ZIP جدید **`2.0.0-beta.3`** روی پورت جداگانه **8766** اجرا می‌شود.

- ZIP را در پوشهٔ تازه استخراج کنید، نه روی نسخهٔ قبلی.
- `RUN_DEMO_WINDOWS.bat` را اجرا کنید.
- `http://127.0.0.1:8766/operations` را باز کنید.
- `http://127.0.0.1:8766/__sanequeue__/build` باید `version: 2.0.0-beta.3`, `fake_data: true` و `controls_locked: true` داشته باشد.
- `Ctrl+Shift+R` برای حذف کش.
- `CHECK_RUNNING_DEMOS.ps1` یک ابزار **خواندنی** برای شناسایی PID دو پورت است، هیچ پردازشی را متوقف نمی‌کند.

**این نسخه هنوز به PBX واقعی وصل نمی‌شود؛ Demo فقط با داده ساختگی است و APIهای کنترلی را عمداً می‌بندد.**

# نمودارهای سبک گزارش

این ابزار فقط دادهٔ کامل و مجازِ همان پاسخ گزارش را به نمودار میله‌ای ثابت و جدول معادل تبدیل می‌کند. هیچ درخواست شبکه، کتابخانهٔ بیرونی، انیمیشن، فراخوانی PBX یا خواندن جدول HTML ندارد. محور نمودار از صفر شروع می‌شود. زمان بر حسب ثانیه را با تعداد تماس یا درصد در یک محور مخلوط نکنید؛ پاسخ‌های کارشناس و AHT نمودارهای جدا می‌خواهند.

## استفاده

فایل‌های `static/css/report-charts.css` و `static/js/report-charts.js` را از `theme_static` قالب فعلی بارگذاری کنید؛ اسکریپت با `defer` و پیش از اسکریپت مصرف‌کننده باشد. این فایل مستقل به‌تنهایی نمودار هیچ گزارش موجودی را فعال نمی‌کند.

```javascript
const host = document.getElementById('history-queue-wait-chart');
SaneQueueReportCharts.clear(host); // قبل از هر درخواست تازه
// فقط بعد از اعتبارسنجی generation / دوره / مجوز پاسخ در مصرف‌کننده:
SaneQueueReportCharts.render(host, {
  title: 'میانگین انتظار صف',
  subtitle: '۱۴۰۵/۰۸/۰۱ تا ۱۴۰۵/۰۸/۰۲ · تهران · صف‌های مجاز ۸۰۰۱، ۸۰۰۲',
  labels: ['۸۰۰۱', '۸۰۰۲'],
  series: [{label: 'میانگین انتظار پاسخ‌داده‌شده‌ها', values: [0, null]}],
  unit: 'ثانیه'
});
// در catch، عدم دسترسی، دادهٔ ناقص یا خروج از view هم clear(host) کنید.
```

`render` مقدار `true` برای نمایش و `false` برای میزبان پنهان/خارج از گزارش یا دادهٔ نامعتبر می‌دهد. `clear` داده و کنترل‌های خروجی همان میزبان را پاک می‌کند. میزبان باید به سند متصل، در نمای `body.dataset.view === 'reports'` و خارج از هر والد دارای `hidden` باشد. API نیازی به ID خاص ندارد.

## معنای داده

- `labels` و `series` آرایه‌اند؛ هر سری دقیقاً به تعداد دسته‌های ورودی مقدار دارد. متن عنوان حداکثر ۱۶۰، زیرعنوان ۱۰۰۰، دسته/نام سری ۱۲۰ و واحد ۴۰ نویسه است.
- فقط عدد متناهیِ نامنفی تا `1e12` یا `null` معتبر است؛ رشته، `undefined`، خانهٔ خالی آرایه، مقدار منفی و `NaN` رد می‌شوند. `null` با خط تیره/«نامعلوم» و صفر با نشان صفر نمایش داده می‌شود. نامعلوم هرگز صفر یا فاصلهٔ تخمینی نیست.
- فقط ۶۰ دسته و ۴ سری نخست نمایش داده می‌شوند؛ اگر بیشتر باشد اعلان محدودسازی در صفحه و خود SVG می‌آید. این برش، رتبه‌بندی یا نمونهٔ آماری نیست. مصرف‌کننده باید ترتیب و عنوان دقیق را از گزارش بدهد.
- `maximum` اختیاری و نامنفی است؛ کمتر از بزرگ‌ترین مقدار واقعی، محور را کوچک نمی‌کند. در نبود مقدار مثبت، مقیاس ۰ تا ۱ صرفاً برای رسم است، نه دادهٔ تولیدشده.
- جدول در «نمایش جدول مقادیر قابل‌دسترسی» همیشه موجود است و متن کامل دسته‌ها را دارد. برچسب بلندِ شکل برای خوانایی کوتاه می‌شود. نمایش تا دو رقم اعشار گرد می‌شود؛ محاسبهٔ آماری یا تغییر واحد انجام نمی‌شود.
- مخرج SLA، نمونه‌های دارای مدت معلوم، تعریف AHT/ASA و پوشش باید از backend و زیرعنوان گزارش مشخص شوند. نمودار هیچ مخرج یا آمار گمشده‌ای نمی‌سازد. عنوان و زیرعنوان باید دوره، timezone، فیلتر و جزئی/کامل بودن نتیجه را صریح بگویند. شماره‌ها باید قبلاً سمت سرور پوشانده شده باشند.

## عمر داده و خروجی

با `input/change/submit` فرم `history-filters`، رویداد `sanequeue:reports-loaded`، خروج از گزارش، پنهان‌شدن بخش یا جداشدن میزبان، شکل پاک می‌شود. صدور فایل وضعیت view/visibility و snapshot مقدار فیلترهای فرم را دوباره بررسی می‌کند؛ PNG پیش از رسم و هنگام آماده‌شدن فایل نیز بررسی می‌شود. تغییر و سپس بازگرداندن فیلتر پس از رویداد، شکل قبلی را برنمی‌گرداند.

مصرف‌کننده همچنان باید درخواست قبلی را لغو و generation پاسخ را بررسی کند، و با تغییر فیلتر محلی خارج از فرم مرکزی یا خطا `clear` را صدا بزند. helper از رسیدن پاسخ کهنه جلوگیری نمی‌کند؛ فقط شکلِ موجود را پاک می‌کند. دادهٔ قابل‌استفادهٔ مجدد در متغیر سراسری نگهداری نمی‌شود؛ WeakMap صرفاً snapshot اعتبار میزبان را نگه می‌دارد.

دکمهٔ SVG شکل مستقل با عنوان، دوره، واحد، راهنما و مقادیر می‌دهد. PNG اختیاری در مرورگر دارای Canvas و Image، از همان SVG محلی ساخته می‌شود؛ خرابی پشتیبانی خطای روشن می‌دهد. فونت فارسی از فونت‌های موجود مرورگر/سیستم می‌آید؛ فونت خارجی دانلود یا داخل SVG جاسازی نمی‌شود. این فایل‌ها خروجی تصویری‌اند، نه PDF/Excel رسمی یا خروجی کل داده. فایل دانلودشده پس از تغییر مجوز قابل پس‌گرفتن نیست؛ شکل هیچ مجوز اضافه‌ای ایجاد نمی‌کند.

آزمون کد واقعی: `node tests/report_charts_frontend.cjs`، دادهٔ مصنوعی و بدون سرور. این آزمون پیکسل یا ظاهر مرورگر واقعی را تأیید نمی‌کند؛ چیدمان صفحهٔ یکپارچه باید جدا بازبینی شود.


Integrated reports: answered/abandoned trends, queue ASA/wait percentiles, agent queue-segment answer counts and AHT (separate units), CDR trunk/DID aggregate traffic, elapsed shift evidence, full-period pause-call outcomes and temporal VIP volume/SLA. Null denominators/unknown durations remain unknown. These use the same response as the corresponding tables and introduce no extra HTTP/AMI queries. Input/change/submit, local CDR filters and the VIP SLA threshold invalidate pending charts. The screen inherits theme colors; image exports use explicit white backgrounds for portable slides. Empty scope displays no-data text and no image-export controls. Category labels allow up to 512 characters; the original table retains complete names.
